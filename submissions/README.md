# Your submissions

Create **one folder per exercise** under your GitHub username:

```
submissions/
└── <your-github-username>/
    ├── 2.1/index.html
    ├── 2.2/index.html + app.js
    ├── 2.3/form.html + validation.js
    └── 2.4/index.html + app.js
```

Rules:
- Only touch your own folder.
- Copy the starter files from `exercises/<exercise>/starter/` first.
- Open your page at `http://localhost:8000/submissions/<username>/2.1/` after running `python scripts/serve.py`.
